# Differences from Qwen2.5-Math/evaluation/requirements.txt:

#   * sympy is 1.13.1 instead of 1.12 because torch 2.5.1 requires exactly
#     1.13.1; answer grading on the six benchmarks was spot-checked to be
#     identical under both versions;
#   * flash_attn is omitted: the toolkit never imports it and vLLM ships its
#     own attention kernels.
